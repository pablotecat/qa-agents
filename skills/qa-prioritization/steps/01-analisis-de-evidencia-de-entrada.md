# Paso 1: Analisis de Evidencia de Entrada

## Objetivo del Paso

Determinar que evidencia es util para priorizar y que limites impone antes de emitir decisiones.

## Enfoque Exclusivo

Durante este paso lee e inventaria; no asignes prioridad, etiquetas ni decisiones de automatizacion.

## Secuencia

1. Lee las fuentes disponibles e identifica si contienen tests, suites, requisitos, riesgos, precondiciones o dependencias.
2. Registra el tipo, origen, fecha disponible y legibilidad de cada fuente.
3. Clasifica la evidencia como confirmada, parcial o ausente para riesgo, automatizacion y orden manual.
4. Registra los GAP que impidan evaluar algun aspecto, sin detener el workflow.

## Checklist de completitud

- [ ] Todas las fuentes accesibles estan inventariadas.
- [ ] Se identifico la granularidad disponible: suite, caso, requisito o flujo.
- [ ] Cada limite de evidencia esta registrado como GAP o decision pendiente.
